# Guides

Guides explain how to work with the current repository and runtime. They do
not redefine field semantics, runtime guarantees, or roadmap priority.

- [Development guide](development.md) covers prerequisites, focused checks,
  the canonical `scripts/check.sh` gate, and common failure diagnosis.
- [v1alpha1 to v1alpha2 migration](migrating-v1alpha1-to-v1alpha2.md) gives
  the authority-preserving path from the compatibility form to concise safe
  authoring.

For field semantics and executable behavior, use the
[reference](../reference/README.md); for durable authority boundaries, use
[architecture](../architecture/README.md).
