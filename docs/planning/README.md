# Planning

[ROADMAP.md](../../ROADMAP.md) at the repository root is AgentFlow's canonical
roadmap and governance boundary. This page is documentation navigation and
execution guidance; it does not duplicate the roadmap's priority list,
completion status, or exit criteria.

## Choosing work

Read the product direction and current priorities in the root roadmap, then
choose a bounded item whose prerequisites are satisfied. Confirm the relevant
architecture, reference, research, and evidence documents before changing
scope. Keep implementation work and its validation claims aligned with the
roadmap item being addressed.

## Completing work

When a roadmap item is completed, update the canonical roadmap only through its
normal governance workflow. Record durable execution and verification claims
in the appropriate [evidence](../evidence/README.md) document, and update
supporting guides or references when the product behavior or contributor
workflow changes. Research may inform the decision, but it does not silently
become a requirement or change roadmap priority.

For self-hosted work, retain the run's durable proof in evidence and keep that
proof linked from the relevant self-hosting guide so a completion claim remains
auditable.

Planning status is intentionally not copied here: readers should follow
[ROADMAP.md](../../ROADMAP.md) for the one source of truth.
